# 🍭 Lollipop Clicker TEST

Versão de testes do jogo estilo *cookie clicker* de pirulito, desenvolvido do zero com tecnologias web puras e otimizado para dispositivos móveis.

## 🚀 Recursos do Jogo

- 📱 **PWA (Progressive Web App):** Pode ser instalado no celular e jogado offline.
- 🎨 **Visual & Animações:** Efeitos de partículas a cada toque e layout responsivo.
- 🔊 **Sons Sintetizados:** Áudio nativo usando Web Audio API (sem carregar arquivos de som pesados).
- 💾 **Salvamento Automático:** Salva o progresso no navegador e calcula ganhos offline.
- 🌟 **Eventos Especiais:** Pirulitos dourados bônus aparecem aleatoriamente na tela.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Service Workers & Web App Manifest
